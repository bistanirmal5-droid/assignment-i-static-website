This is my first FDD assignment.


This project is a static website developed for Kathmandu Warriors FC.
It showcases the football club’s identity, including team information, matches, stadiums, and resources.

The website is built using HTML and CSS with a focus on modern design, responsiveness, and user experience.

Objective:
To design a clean and responsive football club website
To practice semantic HTML structure
To apply modern CSS styling techniques
To create an attractive UI with images, icons, and layout

Technologies Used:
HTML
CSS
Google Fonts (Poppins)
Font Awesome (for social media icons)
